# YouTube Live Timestamp

YouTube のライブ配信を視聴中に、ショートカット一発で「配信開始からの経過時間」を記録する Chrome 拡張（Manifest V3 / TypeScript / WXT）。アーカイブ / 通常動画では再生位置を記録する。再生位置の微調整（0.1 秒〜5 分）と、今のフレームのスクリーンショット保存もできる。

## 使い方

1. `npm install && npm run build`
2. `chrome://extensions` → 「デベロッパーモード」→「パッケージ化されていない拡張機能を読み込む」→ `dist/chrome-mv3/` を選択
3. YouTube の動画ページで **Alt+Shift+T** を押すか、拡張アイコン → **「● 記録」** で記録。バッジに件数が出る（ライブ配信中は「配信開始からの経過時間」、アーカイブ / 通常動画は再生位置）
4. 拡張アイコンをクリックすると**配信ごと**の記録一覧（配信タイトルが親、記録が子。今開いている配信は先頭で展開）。配信ごとに「コピー」「削除」、各記録のメモ欄をクリックすると一言メモを付けられる。「補正」で視聴遅延分の秒数を調整（例: 配信が 10 秒遅れて見えているなら `-10`）。各行のリンクは `watch?v=...&t=...s` で VOD 位置を開く。「テキストをコピー」で配信ごとに `# タイトル` + URL + `h:mm:ss メモ` の一覧（コメント・概要欄用）、「JSON」で全件バックアップ
5. popup の **スキップ行**（`-5m` 〜 `-0.1s` / `+0.1s` 〜 `+5m`）で再生位置を動かせる。一時停止中も効くので「一時停止 → 0.1 秒ずつ → 📷」でコマ送りできる。押すたびに「ライブより N 秒前」が出る
6. **📷** または **Alt+Shift+S** で今のフレームを `~/Downloads/ss/` に PNG で保存し、**同じ瞬間のタイムスタンプも記録**する（メモにファイル名が入る。ファイル名は `日時_videoId_経過.png`、バッジに `SS`）。**📁** で最新のスクショを Finder に表示する。別の場所に置きたい場合は `ln -s <実体> ~/Downloads/ss` を張ればよい

- 同じ配信で 1.5 秒以内の連打は重複として無視（バッジ `=`）。記録は最大 5000 件で古い順に消える
- 記録・スクショの経過時間は「実時刻 − 配信開始」から**ライブ端からの遅れ**（巻き戻し・一時停止分）を引いた値。ライブ端で見ているときもプレイヤー遅延の数秒が自動で引かれるので、以前より「補正」を小さめにするとよい
- **アーカイブ / 通常動画でも使える。** 配信中でない動画では再生位置（`t=` と同じ時間軸）をそのまま記録する。「補正」はライブ配信のときだけ効く
- 権限は `storage`（記録）と `downloads`（スクショ保存とフォルダ表示）のみ

ショートカットが他と衝突する場合は `chrome://extensions/shortcuts` で変更できる。

